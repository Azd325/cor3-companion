# Privacy policy

*COR3 Companion, last updated 19 November 2026*

COR3 Companion is a browser extension that adds helpers to the cor3.gg game. It collects no personal
data, and it has no account, analytics, ads or tracking.

## What it reads

- It runs only on pages of `cor3.gg` (that is the only site it has access to).
- On those pages it reads what the game already shows and sends to your browser (for example your jobs,
  your loadout and the market), so it can show its helpers. This stays in your browser.
- It never sends anything to the game, and it doesn't send what it reads to anyone else.

## What it stores

- Your helper switches, panel positions and the game data the helpers need (for example the network map
  and your HACK power) are saved in your browser's storage for cor3.gg. They never leave your computer.
- Uninstalling the extension, or clearing cor3.gg's site data, removes them.

## Network requests

- Copies installed from the Chrome Web Store make no requests of their own.
- Other copies (Firefox, or Chrome loaded by hand) ask GitHub for the number of the latest release, at
  most every 6 hours and only while the toolbar menu is open, to show a line when a newer version is out.
  This is an ordinary request to `api.github.com` with no data about you or the game in it; GitHub sees
  it like any other visit (see [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)).

## Contact
